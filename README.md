# AMINO STUDIO

AMINO STUDIO static pricelist website.

## Files

- `index.html` — main website page
- `style.css` — website styling
- `logo.png` — AMINO STUDIO logo
- `README.md` — project notes

## Deployment

This project is designed to be deployed as a simple static website on Vercel.

### GitHub

Upload all four files to the root of the GitHub repository:

```text
index.html
style.css
logo.png
README.md
```

Do not upload the ZIP file itself.

### Vercel

If the GitHub repository is already connected to Vercel, committing changes to the repository should trigger a new deployment automatically.

## Current website features

- AMINO STUDIO branding and centered logo
- Full pricelist
- Search by code or product
- Group-buy information and fee notices
- Telegram contact button for `@Amino0208`

## Current scope

This version intentionally keeps the website simple.

The following features are NOT included in this version:

- Falling peaches
- Falling hearts
- Filter dropdown
- Quantity selector
- Save buttons
- Saved inquiry list
- Remove-item controls
- Checkout/payment collection

These can be added later as separate features.
